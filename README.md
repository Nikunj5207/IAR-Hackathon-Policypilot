# 🚀 PolicyPilot – AI Powered Government Scheme Assistant

PolicyPilot is an intelligent AI-based web platform designed to help citizens easily discover, understand, and apply for government welfare schemes.
It simplifies complex policy documents into easy insights and provides personalized scheme recommendations.

---

## 🎯 Problem Statement

Many citizens are unaware of the government schemes they are eligible for due to:

* Complex policy documents
* Language barriers
* Lack of digital awareness
* Difficulty in comparing multiple schemes

PolicyPilot solves this by providing an **AI-driven conversational assistant** that guides users step-by-step.

---

## 💡 Key Features

✅ AI Chat Assistant for scheme guidance
✅ Personalized scheme eligibility detection
✅ Multi-language interaction support
✅ Document upload & analysis
✅ Conflict detection between schemes
✅ Simple and user-friendly UI
✅ Fast search using RAG (Retrieval Augmented Generation)
